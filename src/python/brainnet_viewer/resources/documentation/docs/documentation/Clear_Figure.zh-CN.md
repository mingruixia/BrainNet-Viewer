# 清空绘图（Clear Figure）

点击Scene工具栏 **Clear Figure**，关闭内嵌、弹出及兼容渲染视图，恢复启动面板。
输入文件、已加载数据、已应用显示配置及导出偏好保留，不删除或覆盖磁盘文件。
几何缓存保留，便于快速再次绘制。

现代主渲染视图的最新相机写入Scene会话状态；再次 **Render Scene** 恢复配置与
相机，并重新允许图片导出。仅在弹出窗口修改的相机不合并到主视图。
清图后保存Scene仍可保留主相机，供后续重放。

清图会关闭查询交互及空闲的动画导出窗口，暂时禁用依赖现有绘图的操作/导出。
动画导出进行中需先完成或取消；此时Clear Figure只报提示，不清理任何绘图。
右侧未Apply的编辑不会被Clear Figure清掉，但仍需Apply才能提交。清图不等于
Apply、Revert或恢复默认设置。

- 画布工具栏 **Reset**：恢复相机。
- 设置面板 **Revert**：恢复上次已应用的设置。
- **Restore Defaults...**：[确认后替换显示配置](Restore_Defaults.zh-CN.md)，与只清绘图不同。
- Data Sources各角色旁 **Clear**：移除对应输入。
- **Clear Figure**：只清当前绘图，可重复调用。

程序接口为`app.clearFigure()`；存在渲染视图时按钮可用。空闲/未加载时调用不会
读取输入或触发绘图。
