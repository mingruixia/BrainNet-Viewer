# Double Brain 双脑显示

加载曲面，可同时加载节点及连边矩阵。Layout选择**Single View**，方向选择**Left (Sagittal)**、**Superior (Axial)**或**Anterior (Coronal)**。在右侧**Surface**勾选**Double Brain**，使用全局**Apply**提交并渲染。取消勾选恢复单脑；Revert回到最近应用值，Restore Defaults会关闭此选项。

## 节点顺序是数据约定

Double Brain显示两份曲面，并分别使用节点文件中的两组数据。N行节点中的第1至floor(N/2)行属于第一个脑，其余行属于第二个脑。两组按此顺序连续放置，原始坐标使用同一坐标系。连边矩阵的行列对应完整节点原始顺序，允许跨脑连接。奇数N沿用旧版floor分组；不会自动识别被试、半球或节点对应关系。

两个脑共用同一曲面，可统一颜色，也可使用[独立Vertex RGB](Vertex_RGB.zh-CN.md)。第二个曲面仅为显示副本。左侧视角把副本绕Z轴旋转180度并沿Y分开；顶视/前视沿正/负X平移。保留旧公式基于曲面宽度的10%间距；若节点球体很大，可能需要缩小节点。双脑处于同一坐标轴，初始相机适配两脑合并范围。

仅显示坐标变化，输入文件、原始坐标、编号、筛选、节点值、边权及源空间长度配色不变。标签跟随显示位置；Inspect点击第二脑曲面/节点时将命中点转换回原始坐标，不自动建立图谱配准。跨脑边表达图关系，不是两个平移脑之间的真实物理纤维束。

## 保存与限制

- Settings 1.17新增`surface.double_brain`，默认false；旧Scene/预设升级时关闭。旧EC的`msh.doublebrain`为0/1时可导入、导出保留。
- App Apply、预设兼容检查及渲染入口明确拒绝不支持组合。限于曲面＋可选节点/边、统一或顶点RGB颜色、单视图及上述三个方向。不支持体数据/ROI/标量映射、只有节点无曲面、多视图布局或任意初始方向；绘图后的相机交互和动画仍可使用。
- 自定义边界覆盖两个脑的相同顶点，其余位置保留每脑独立RGB；此选项不适用于任意多被试场景组合。
- Scene/预设JSON、图片元数据、相机恢复及动画克隆保留该设置。开关或方向变化使显示几何按需失效，不重新解释源坐标。
