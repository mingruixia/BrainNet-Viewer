# 窗口布局与截图检查

[English](Window_Layout.en.md) · [迁移说明](Migration.zh-CN.md)

主窗口根据可用宽度调整各列。可以缩放、最大化或还原窗口，未提交的设置和Apply/Revert控件会保留。

窗口改变不自动Reset、Fit或改写科学相机。纵横比变化仍会影响能看到的范围，需要时主动使用Fit。画布继续采用原有归一化多视图轴区域及独立缩放策略。

渲染器在首次绘制后固定初始相机和坐标轴范围。需要重新构图时，使用Fit适配当前几何，或使用Reset恢复布局相机。

Data Sources下方的**Export Figure**仍按设置尺寸导出科学脑图。整窗截图是另一件事：包含界面，可能额外包含原生菜单条。

如果出现裁切，请保存完整窗口截图和Scene，并记录窗口状态、显示器分辨率、缩放比例及操作顺序，便于复现问题。窄窗口中的部分内容需要滚动查看。

![当前完整窗体多视图布局，浅色主题](../tutorials/assets/captures/tutorial07-export/07-layout-4-full-window.png)

设置区域独立滚动，底部Apply/Revert保持可见。窗口缩放不会自动Fit；旧Scene若放大过度，可手动Fit。超出子图范围的标签会暂时隐藏，相机或尺寸变化后重新判断是否可见。这可以避免文字被截断，但不能防止标签相互重叠。
