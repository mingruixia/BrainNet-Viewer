# 导出脑图旋转动画

## 桌面操作

1. 读取数据，按 **Apply** 提交显示设置并通过 **Modern Batch Renderer** 渲染；**Render Scene** 可显式重绘。
2. 按需调整视角，选择 **Tools → Export Animation...**。
3. 选择MP4、AVI或PNG帧序列，设置像素尺寸、时长、帧率、世界X/Y/Z旋转轴及起止偏移角度。
4. 建议保留 **Safe Fit**，使旋转过程中的几何留在画布内；关闭可保留当前取景，但可能裁切。
5. 点击 **Export...**，在已有父目录下填写**新的文件夹名称**。输出是一个结果文件夹，不是单个文件；已有路径禁止覆盖。

![真实曲面教程使用的英文动画设置窗口](../tutorials/assets/captures/tutorial12-animation/12-animation-controls.png)

**Cancel Export** 在当前帧/编解码操作结束后取消，清理暂存文件并保留设置窗口；导出中关闭窗口会先取消，清理后再关闭。导出期间输入控件禁用，失败或取消不会发布半成品文件夹。

导出器用已准备的数值数据建立一次独立、高质量渲染副本，每帧复用几何，不转动主画布，不改变Scene、显示配置或静态图片导出偏好。因此成功、取消、失败都不影响原相机。它是离线导出，播放帧率不代表实际生成速度，本轮不声称实现GPU视频编码加速。

## 角度、时间和取景规则

- 角度是相对当前相机的偏移，不是绝对解剖方位角；正角按指定**世界坐标轴**的右手规则旋转，终点小于起点可反向旋转。
- 每个视图围绕各自目标旋转；每帧从基准相机独立计算位置和up向量，避免累积误差及极点奇异。多视图保持相同相机距离/尺度及固定、互不重叠的轴区域。
- 帧数为 `round(时长 × 帧率)`，实际时长为帧数/帧率。完整±360°不重复终点；局部旋转包含起止端点。是否循环播放由外部播放器控制。
- Safe Fit只调整**导出副本**：将几何居中，使用正交投影和适合全程旋转的包围半径，各视图共享尺度，脑图可能比主画布小。关闭时保留投影、目标、距离和视角大小。
- 相机相对光源跟随旋转；为避免误导，动画副本不显示静态解剖方向标记。节点文字可能超出几何取景边界。

这是静态数据的相机动画，不是时变连接动画，不进行纤维重建、解剖配准或科学坐标变换。

动画背景和样式以已应用的Scene设置为准，不跟随Light/Dark界面主题。独立副本使用完整质量，因此简化的交互画布不是动画的逐像素预览。

## 格式与结果文件夹

| 格式 | 输出 | 说明 |
|---|---|---|
| MP4 | `movie.mp4` | MATLAB MPEG-4配置，质量95；本机可用时才显示 |
| AVI | `movie.avi` | Motion JPEG AVI，质量95，通常文件较大 |
| PNG | `frame-000001.png`等 | 无损逐帧图片 |

每个结果文件夹还包括 `preview.png` 和 `provenance.json`：完整Scene、准备数据指纹、原始/导出基准相机、动画方案、逐帧角度/哈希、渲染器/MATLAB版本和验证帧数。视频逐帧哈希对应**编码前PNG字节**，不等于有损解码像素；最终视频另存文件哈希。不会复制原始输入文件；分享前请核对其中的本地路径与隐私元数据。

视频发布前逐帧解码，核对帧数和尺寸。所有文件先放到同级唯一暂存目录，再禁止覆盖地整体发布。使用的是当前已准备数据，而非重新读取磁盘输入；哈希描述该数值快照，不保证跨平台像素一致或编解码格式均可用。

资源限制：每维128–3840像素、1–60 fps、2–1800帧、请求时长不超过120秒、总帧像素不超过10亿。视频长宽必须为偶数。支持非零、最多360°的旋转；不包括透明背景和音频。

## MATLAB接口

已有App渲染后：

```matlab
record = app.exportMovie("D:/results/orbit-01", ...
    Format="mp4", Width=960, Height=720, ...
    Duration=5, FrameRate=24, Axis="z", ...
    StartAngle=0, EndAngle=360, SafeFit=true);
```

独立接口为 `brainnet.export.MovieExporter.export(renderer, scene, prepared, newFolder, ...)`，参数相同，另支持 `Cancel=@() false` 和 `Progress=@(done,total) []`。渲染器须有当前相机，准备数据须匹配Scene输入/映射缓存键。已有结果文件夹不会被覆盖。
