# 从标签图谱生成节点

[English](Atlas_Nodes.en.md) · [手册](../manual/zh-CN/index.md)

英文主界面入口：**Tools → Generate Nodes from Atlas...**。

1. 选择离散整数NIfTI图谱（`.nii`、`.nii.gz`或NIfTI `.hdr/.img`，含压缩配对）。独立读取器支持NIfTI-1/2，不依赖SPM；不支持纯Analyze 7.5、概率或4-D图谱。
2. Region IDs留空：按非零ID升序生成；或用空格/逗号输入不重复且存在的ID，保留指定顺序。允许负ID，0为背景。不支持范围表达式或自动查询区域名称。
3. 设置统一的Color / module和Size value，点击**Review Atlas**。两项默认均为**0**，与旧`BrainNet_GenCoord`一致；大小0不保证可见，绘制时可设置合适数值或采用Uniform节点大小。
4. 核对区域计数、仿射来源、坐标及文件指纹，填写并确认图谱仿射对应的坐标空间和单位。填写声明不会转换坐标。修改文件或生成选项后须重新Review。
5. **Save New .node...**仅新建文件，已有目标拒绝覆盖；取消不写出。图谱或配对成员变更后须重新审阅。原图谱和当前Scene均不自动改变。
6. 通过**Node Coordinates**加载结果，再配置与渲染；连边矩阵行列顺序必须与所选区域顺序一致。

## 科学含义与边界

每个标签区域先计算**一基体素中心索引**的无权均值，再乘以读取器对应的一基仿射矩阵。保留旧质心规则，适用于剪切/反向仿射，不额外加半体素偏移。采用读取器的仿射选择规则，不自动配准、推断MNI/mm、重采样标签或把质心移动到区域内。凹形或不连通区域的质心可能在区域外。读取器先应用强度缩放，再检查整数标签。

每行`X Y Z module size label`，label为原数值ID；所有节点使用统一模块/大小值。`#` JSON注释保存来源路径/SHA-256（配对文件两个成员）、区域顺序/体素数、质心算法、仿射、声明空间/单位及时间。分享前检查路径信息。现代节点读取器支持注释，未认证所有外部`.node`读取器。

按100万体素分块分组累加，避免每个区域重复扫描全图。读取和初始唯一标签统计仍使用完整图谱，并非流式、CPU多核或GPU加速，也未宣称实测提速倍数。最多100000个非零标签；窗口预览前100个，保存全部已审阅节点。不修改设置Schema、不自动加载Scene。
