# Scene、预设与旧版配置

[手册目录](index.md) · [English](../en/M03_Scenes_Presets_Legacy.md) · [上一章：数据与坐标](M02_Data_Formats_Coordinates.md)

Scene用于恢复输入和显示设置，预设用于复用外观，Import Settings用于转换可信的旧配置。

## 选择合适的文件

| 需求 | 使用 | 包含内容 |
|---|---|---|
| 重新打开完整可视化 | Scene JSON | 输入引用及哈希、已应用的显示设置，以及受支持的相机/导出会话状态；不包含原始数据字节 |
| 将显示样式用于其他数据 | Visualization Preset | 仅显示设置；不包含输入文件、相机或导出目的地 |
| 恢复可信的旧项目 | 旧配置导入 | 需要逐字段复核的迁移起点，而非无损的现代Scene |

## 保存及重新打开Scene

先加载并验证输入、设置可视化，再按**Apply**提交并渲染。然后在主窗口保存Scene JSON。Scene尽可能记录相对配置数据根目录的路径，并通过哈希验证所引用输入；不内嵌曲面、节点、连边或体数据。移动项目时，须一并保留输入及兼容的目录结构。根目录以外的文件须按[M01](M01_Installation_Launch.md)的显式导入/暂存流程处理；选中外部文件并不自动取得再分发权。

重新打开时，检查解析后的路径、哈希、文件角色、空间对齐和渲染结果。若输入缺失或改变，应查明原因，不应绕过校验。Scene重放可恢复受支持的相机和导出偏好，但旧Scene未必能表达后续新增的所有选项。详细结构、路径和命令行行为见[Scene流程](../../documentation/Scene_Workflows.zh-CN.md)。

## 应用显示预设

加载目标数据后再选择预设。加载预设会替换各显示设置部分，不导入输入文件，也不保留未提交编辑或相机状态。检查控件后，用**Render Scene**显式重绘。如需保存输入与显示的组合，再保存新的Scene JSON。支持的字段及重置行为见[显示预设](../../documentation/Visualization_Presets.zh-CN.md)。

## 导入旧版配置

只导入来源可信的旧MAT配置。迁移会转换能够转换的字段，并报告需要复核的字段；不保证历史渲染完全一致。逐一检查文件角色、路径、布局、阈值、颜色及导出选项，采用前对比代表性图像。导入成功不等于新旧功能完全对等。当前限制见[迁移与故障排查](M15_Migration_Troubleshooting.md)。

## 批处理与溯源

如需可重复的非交互渲染，可让`BrainNetRender`使用经复核的Scene。Scene JSON、输入校验和导出溯源有助于复原图片，但仍需记录数据来源、图谱版本、坐标约定、软件构建及人工决定。批处理见[M14](M14_Batch_Provenance.md)。分享Scene前，应检查路径、元数据和旁侧文件有无本机隐私信息；分享JSON也不构成分享其引用数据的授权。
