# 单曲面转换为NV

[English](Surface_Conversion.en.md) · [手册](../manual/zh-CN/index.md)

1. **Tools → Convert Surface to NV... → Choose File...**，选择`.nv`、`.pial`、`.mesh`、BYU `.g`、MNI/BIC `.obj`（不是通用Wavefront OBJ）、`.mz3/.mz3.gz`或`.gii/.gii.gz`；沿用各读取器限制。
2. **Review Inputs**核对源路径/指纹、顶点/面片数量、索引范围及坐标范围。只接受一个输入，多文件使用[Merge Surfaces](Surface_Merging.zh-CN.md)。
3. Raw space、单位及备注可留空；未知空间/单位记录为`unknown`。确认**仅几何转换**：保留读取器返回的坐标、顶点顺序、面片连接及绕序。不传递颜色、标量图、材质、法线或语义标签；GIfTI变换仅记录来源，不应用或激活。
4. **Save New .nv...**写出17位有效数字ASCII，精确读回核对后发布。已有目标（包括原文件）禁止覆盖；输入或GIfTI外部数组变更后必须重新审阅。取消选择/保存不写出。
5. 通过**Surface Mesh**加载结果，配置后渲染；当前Scene和源文件不自动改变。与其他Scene输入一致，文件需位于App配置的数据根目录内，或使用合适的数据根目录。

## 与旧版的重要差异

旧`BrainNet_MergeMesh`单文件`.mesh`分支固定执行`91-X、91-Y、109-Z`。现代转换器**不沿用该特定数据假设**，保留读取器/原始坐标，不自动配准、换单位、缩放、镜像、细分、简化或修复。需要对齐时应另行建立明确变换，不从文件名或扩展名推断MNI。保留的是几何与拓扑，并非所有原文件属性或字节。

第二行`#`注释为JSON来源记录：源/外部依赖路径及SHA-256、可用原生元数据、数量/范围、可选声明及时间。注释中的元数据不会被NV读取器自动激活或赋予Scene。分享前检查绝对路径；转换不改变资源再分发权限。

默认上限为500万顶点/1000万三角面片，在输入读取后检查。几何与读回复核需要内存；不是流式或GPU加速，最终哈希也不是文件系统快照。Settings/Scene Schema不变；未做完整回归或旧GUI认证。
