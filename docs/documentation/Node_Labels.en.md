# Node typography and placement — development build

In **Visualization Settings → Nodes**, choose Label Mode, font name/size, **Font Style** (Normal/Bold, Normal/Italic), **Font Units**, Label Color and Keep Labels in Front. The single global Apply commits and renders; Revert discards uncommitted changes. Labels remain literal text: underscores and backslashes are not interpreted as TeX; a lone `-` suppresses a label. Visibility/strict threshold rules from focused check are unchanged.

Typography now round-trips legacy `EC.lbl_font.FontName/FontSize/FontWeight/FontAngle/FontUnits`. Units include points, pixels, normalized, inches and centimeters; size must be positive and at most 100 in the selected unit. Changing units does not convert the numeric size: choose a suitable value, particularly for normalized/physical units. Actual glyph availability depends on installed fonts; points are recommended for publication figures.

Labels are placed above their nodes using the displayed node radius plus one coordinate unit along the camera's screen-up direction. Each view has its own anchors, updated on rotation, camera restore, Fit and Reset. This is a deliberate modern alternative to legacy view-index-specific x/y/z offsets and mixed alignment, not pixel-identical reproduction. Node coordinates and scientific geometry are unchanged.

Keep Labels in Front projects anchors onto a camera-facing plane beyond the displayed geometry bounds; perspective projection preserves the anchor's screen position. It replaces the ineffective 0.8-unit radial shift. It is a depth-placement feature, **not label collision avoidance**: dense labels can still overlap. focused check checks projected glyph boxes and temporarily hides entire labels that would cross a pane boundary. Camera/size changes re-evaluate visibility; zoom, pan, enlarge the pane or reduce font size as appropriate. Text is not truncated or automatically resized. Automatic collision avoidance and all-DPI export acceptance remain open. If the camera is inside the geometry bounds, no plane can be in front of all geometry while remaining in front of the viewer; the layout falls back to the radius-aware anchors. Labels do not intercept node/atlas picking.

Settings **1.14.0** adds weight, angle and units. Older modern files retain Normal/Normal/Points defaults; reimport the original EC to recover previously omitted typography. Scene migration flags placement review and rebinds only valid old camera signatures. Scene/presets preserve typography. Existing screenshots can change because of the corrected placement.

Focused checks do not establish complete legacy parity or current-build visual acceptance across display sizes.
