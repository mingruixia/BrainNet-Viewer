# 全显示设置恢复默认

右侧设置面板固定底栏的 **Restore Defaults...** 位于唯一一组 **Revert / Apply**
上方，作用于全部显示类别，不只当前展开的类别。确认框说明覆盖范围，默认选项及
关闭/取消操作均为 **Cancel**；取消不会改动当前图或未提交编辑。

确认后，布局、全局外观、曲面、节点、连边、体数据/ROI及纤维设置恢复版本定义的
默认值；标题和色条注释也重置。已应用自定义配色、掩码等元素设置被替换，未提交
编辑被丢弃。**恢复默认后，Revert不能还原此前的设置**；需要保留旧风格时，请先保存
Scene或预设。

保留输入、坐标/方向声明、查询配置、Scene身份、导出偏好（含图片宽高/DPI）及
界面主题，不修改磁盘文件。保留已有画布，不返回欢迎页，仅提示点击 **Apply** 或
**Render Scene** 以默认设置重绘；保存的相机状态重置，供下一次渲染使用。保留的
画布仅作预览，重绘前暂停导出，不自动渲染或导出。动画导出中需先结束或取消。

区别：**Revert**仅撤销未提交编辑；画布 **Reset**仅恢复相机；**Clear Figure**
保留已应用风格及主相机用于再次渲染；**Restore Defaults...**确认后真正替换显示配置。

程序调用需明确确认：

```matlab
report = app.resetVisualizationSettings(Confirmed=true);
```

不提供确认时仅返回`status = 'cancelled'`，不修改状态；隐藏App的按钮回调不会
自动确认，避免无界面运行时意外覆盖。
