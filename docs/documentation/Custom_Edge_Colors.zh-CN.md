# 自定义连边配色：开发版

[English](Custom_Edge_Colors.en.md)

1. 读取原始节点和连边文件，选择 **Edges > Color Mode > Custom Matrix**。
2. **Load Colors...**读取空白分隔的`.txt/.edge`矩阵（支持`#`注释），或包含`matrix`、`indices`、`colors`的JSON。确认行列对应原始节点顺序；读取只是暂存，点击全局 **Apply** 即提交并渲染。
3. 文本矩阵将全部类别（包括0）排序后对应当前色表。JSON保留指定类别顺序及RGB。命名色图生成至少两色；数值色表直接使用前K行，不插值且至少需要K行。单类别JSON的单行RGB内部复制为两行，不改变实际颜色。
4. EC导入的数据尚未绑定：点击 **Bind to Nodes**、确认并Apply。**Revert**撤销暂存；Scene/预设内嵌矩阵、类别顺序、色表及绑定。

有向边i→j读取matrix(i,j)，反向可以不同；按类别数值精确匹配颜色行。拒绝重复类别、非法RGB、非方阵/非有限值、节点数不匹配、缺少绑定及已选边未定义的类别。未使用的矩阵格可以没有类别映射。颜色不改变连边选择、权重、粗细或透明度。

上限：400万矩阵元素、4096类别、输入文件64MB；不受模块配色的20模块限制。以下示例对应按相同顺序排列的三个节点，可分别保存为 `.txt` 或 `.json`；这是文档示例，不是随包发布的测试样例。

```text
# 有向类别，包括作为显式类别的零。
0 -2 7
7 0 -2
-2 7 0
```

```json
{"matrix":[[0,-2,7],[7,0,-2],[-2,7,0]],"indices":[7,-2,0],"colors":[[1,0,0],[0,0,1],[0.5,0.5,0.5]]}
```

Settings **1.11.0**新增`edge.custom_color`。旧Custom配置没有可恢复矩阵，迁移为空，必须加载并绑定后才能渲染。EC color=6导入/导出实际`color_custom_matrix`、`color_custom_index`、`CM`，并写出CM_custom；不执行表达式，缺少EC数据时报错。EC不保存现代绑定，重新导入需确认；App中Custom要求Modern Batch Renderer。

绑定检查的是**有序节点坐标**，不是解剖身份；重合坐标节点无法仅凭坐标区分。它防止后续坐标/顺序变化，不能证明初始对应正确。预设不会静默重新绑定新节点。保存文件可能含本地来源路径，公开前需检查；相机只在旧签名有效时重绑。本轮不重新认证原生对话框及全界面视觉。
