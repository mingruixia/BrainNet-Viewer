# 每顶点RGB与双脑独立配色

在Data Sources选择曲面。如需双脑，先在**Surface**勾选**Double Brain**，再点击**Load RGB...**并确认色表行序与原始曲面顶点一致。此操作暂存**Vertex RGB**模式，使用唯一的全局**Apply**提交并渲染。**Revert**放弃尚未应用的编辑。**Bind RGB**可把已有/旧EC导入的表确认绑定到当前曲面，但不能判断最初的对应关系是否正确。

## 文本格式

空白分隔TXT，每个非空行恰好三个有限数，范围**[0,1]**。支持空格、制表符及`#`注释；不含表头、顶点编号或Alpha列，不自动换算0–255。格式错误明确拒绝，不跳过坏行。上限为1,000,000行RGB、每文件64 MiB。

```text
# 三个连续顶点依次为红、绿、蓝
1 0 0
0 1 0
0 0 1
```

N个顶点的曲面，单脑需N行；双脑需2N行：前N行给第一个脑，后N行给第二个脑，各自遵循同一原始曲面的顶点顺序。这不同于[Double Brain](Double_Brain.zh-CN.md)的节点行序分组。切换脑数量后需换成匹配行数的表，或选择Uniform。RGB是曲面颜色，不是统计图或配准。

## 渲染与安全边界

- 绑定指纹包含有序坐标及面片；曲面改变/重排或行数不符时，在替换旧绘图前拒绝。指纹不能证明最初的解剖对应关系，仍需用户确认。
- Vertex RGB启用时保留原始网格，即使选择Interactive性能模式也不简化，不猜测重采样颜色；高分辨率曲面可能因此较慢。
- RGB不经过标量色图，不显示曲面标量色条；全局插值/平面/网格着色及光照仍影响视觉效果。各多视图布局按原始顶点索引选取颜色。
- 自定义边界掩膜只覆盖指定顶点。双脑未标记顶点各自保留独立RGB；源坐标及Inspect不变。
- Settings 1.18在Scene/预设JSON内保存色表、绑定和来源说明。重放无需原TXT，但仍需曲面文件；较大色表会增大JSON及导出元数据。
- EC导入/导出保留`msh.color_table`和`doublebrain`。旧EC色表必须显式绑定，不假定原对应关系；在无映射上下文且自定义曲面颜色非空时恢复为Vertex RGB。绑定RGB须用Modern Batch Renderer，旧渲染适配器明确拒绝；EC导出不等于旧GUI绘图已认证。

旧配置升级补空色表，不自动启用RGB。此前保存的`vertex-rgb`模式不再悄悄变成Uniform：须导入并绑定，或明确选择其他模式。
