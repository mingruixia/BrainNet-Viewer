# ROI边界与小ROI平滑

渲染器在每个ROI包围盒外补虚拟零背景，包括输入体数据范围之外，
从而封闭贴近体边界面、棱、角的网格。世界坐标继续使用原一基体素仿射，
不平移或重采样输入数据。

网格使用 **0.5等值面**，并非体素立方体的精确并集。边界体素的表面可超出
其中心半个体素，也可超出输入体数据的中心坐标范围；单例维度按单体素厚度处理。

Box/Gaussian仍使用配置的奇数核；偶数核向上取奇数，核为1时不平滑。
专项验证检查原掩码的每个**26邻域连通分量**：每个分量须在原位置至少保留一个
平滑值严格大于0.5的体素，否则将**整个ROI**回退到原掩码的未平滑0.5等值面，
包括其中的大块。不膨胀、不单独拼补孤岛；全部通过时仍使用平滑结果。
这是保守检查，不是严格的曲面对应检验。26邻域仅用于几何保护，
不改变统计簇定义使用的6/18/26邻域，也不改变编号或选择。

有效平滑（核大于1）需要Image Processing Toolbox的`bwconncomp`；
不可用时明确报错，可选择None或核1进行不平滑绘图，不会静默关闭保护。

准备阶段的 `roi_geometry` 溯源记录包括：

- `boundary_policy`：`virtual-zero-halo`；
- `effective_smoothing_kernel`、`isosurface_level`；
- `unsmoothed_fallback_labels`：回退到未平滑网格的编号；
- `component_checks`：各ROI原分量数、风险分量顺序号及原体素数，顺序号不是图谱/簇编号；
- `component_guard_connectivity`、`component_guard_rule`；
- `skipped_labels`：仍未生成网格的编号。

颜色、编号选择、统计阈值及原数组不变。这**不是旧版网格/像素完全对等**。
即使检查通过，平滑仍可能缩小形状、合并/分裂分量或去掉分量内的细分支，
不是完整拓扑或体积保持。升级并重新启动后，旧场景可能出现新闭合边界或
先前缺失的小ROI，应复核几何。Settings仍为1.16。
