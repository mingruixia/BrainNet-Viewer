# 显示设置与统计解释

[English](Scientific_Interpretation.en.md) · [手册](../manual/zh-CN/index.md)

BrainNet Viewer 控制输入数据的显示方式。阈值、颜色和节点大小本身不能证明解剖对应关系或统计显著性。建议随图片保留原始输入、Scene 和导出溯源文件。

## 曲面数值与缺失值

标量曲面映射中，精确零值和非有限值使用曲面底色；其他有限值，包括接近零的非零值，均使用所选色图。色条表示连续数值范围，不再将包含零的整个颜色区间改成底色。输入标量数组不变。

体积映射另有 Adjust Null 及正负显示范围设置。这些显示选项不等同于统计检验。

## P 值与簇大小

P Value (Uncorrected) 根据支持的 NIfTI 统计元数据计算逐体素、未校正阈值。T、R、Z 使用双侧检验，F 使用上尾。只显示正值或负值不会改变检验的单双侧定义。软件不进行 FDR 或家族错误率校正。

Cluster Size 在启用簇筛选时去掉小于指定体素数的连通成分，不是校正后的簇水平 P 值。目前，相邻的正、负保留体素按所选连接规则计入同一成分。若这些设置影响发表图片，应报告具体设置。

## 网络筛选与节点大小

Sparsity 从符合条件的非零、非对角连接中保留指定比例；无向矩阵使用上三角。这不是以全部可能节点对为分母的网络密度。数量边界上的同权重连接按矩阵列优先顺序确定，因此节点顺序可能影响被选中的同权重连接。阈值筛选则保留全部达到阈值的连接。软件不自动将非对称矩阵对称化。

Mapped 节点大小可能先平移、再反复进行对数压缩，之后映射到 2–7 的半径范围；常数输入的半径为 4。Scale 最后乘以半径。半径、投影面积和球体积并不表示同一量。比较不同数据集时，尤其应注意各自的输入范围，并参阅[大小计算规则](Node_Sizes.zh-CN.md)。

## 解剖空间

RAS 和毫米描述坐标轴及单位，并不代表已经配准到 MNI 空间。叠加前应核对参考图像、仿射矩阵及半球对应关系。跨半球连边筛选使用 X 的正负号；X = 0 的节点不会作为同侧连接被排除。此规则要求合适的中线，不能据此推断数据已配准。
