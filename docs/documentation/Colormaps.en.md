# Custom colormaps

See [manual M11](../manual/en/M11_Colormaps_Presets.md) for the desktop workflow and scientific cautions.

The **Colors...** editor has four independent targets: Surface, Nodes, Edges and Volume. Volume has **one** signed colormap; Positive & Negative display splits it at the midpoint, rather than storing two palettes. The separate ROI Label Index categorical palette and optional ROI ID legend are chosen in Volume settings, not in this editor.

Named palettes include Viridis, Plasma, Inferno, Magma and Cividis, using fixed 256-entry Matplotlib reference tables. They appear in Surface, Nodes, Edges, Volume and the ROI Palette selector; the same names are accepted by the Fiber settings data model, although fiber rendering is not yet available. A sequential map is useful for ordered values but can make adjacent ROI categories hard to distinguish. For signed volume values, the selected palette is split at the midpoint; choose a diverging palette such as Blue-White-Red when a meaningful zero-centered contrast is needed. Attribution and source license are in `NOTICE_CODE.md` and `LICENSE_MATPLOTLIB_COLORMAPS.txt`.

Choose a named palette and **Count** (2–4096), then Generate; or import a TXT/JSON RGB table. Edit finite Red/Green/Blue channels in [0,1]. **Resample** interpolates RGB rows, **Reverse** changes order, and **Export...** writes only the current target's table. **Use in Settings** stages the four targets and closes the editor. The single panel-bottom **Apply** commits and renders; **Revert** discards pending settings. Cancel/close discards editor edits.

Continuous color modes resample to 256 colors in RGB space. Mapped nodes use `.node` column 4; Node Threshold and Edge Threshold/Length use fixed colors rather than a continuous colormap. Node Modules are categorical and may cycle when category count exceeds available colors; Edge Node Module inherits the Node module palette for same-module edges, not the Edge palette. A named map stays named unless changed; table edits become embedded arrays. No expression is evaluated on import and no invalid name silently falls back to parula. A palette never changes values, thresholds, registration or statistics. Check signed limits and colorbar before interpreting volume maps.

RGB TXT accepts three numbers per row (spaces/commas, semicolons/newlines and optional surrounding brackets), up to 1 MiB. JSON uses `{"kind":"brainnet-colormap","schema_version":"1.0","colors":[[0,0,1],[1,0,0]]}`. Write operations require explicit overwrite permission. Applied arrays are embedded in modern Scene/preset settings; the legacy renderer rejects unsupported arrays rather than substituting a palette. Old combined `EC.vol.CM` imports cannot be losslessly reconstructed automatically; export RGB from the trusted old application and review the signed mapping manually. Fiber palette fields may exist in settings but fiber rendering and editor targeting are unavailable in this build.
