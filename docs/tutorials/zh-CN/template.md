# 教程撰写模板

[English](../en/template.md)

仅供维护者写作，不是可直接执行的教程。复制为具体教程后必须填全并验收。

## 1. 身份与目标

记录教程ID、中英文标题、软件构建版本、文档复核日期、目标用户及可观察的最终结果。

## 2. 输入与许可

列出相对路径、来源、作者、许可文本、SHA-256、空间/单位/物种及数组规模。说明真实材料、自建示例及内部基准数据；不得含参与者隐私。

## 3. 前提与参数

注明MATLAB/工具箱/平台、实测预计用时、内存要求与参数表。默认值与关键科学假设须有代码或规范依据。

## 4. 编号步骤

使用step-01等稳定锚点；按读取→校验→配置→Apply（**提交并渲染**）→交互/导出编写。Render Scene仅用于显式重绘或加载预设之后。每步有操作、预期状态及检查，不用只靠截图传达参数。

## 5. 预期图与复现

附当前构建的英文全窗截图、导出图、Scene/命令及数值/图像检查。注明是否包含LOD、安全取景或栅格化，不把概念稿当实机证据。

## 6. 常见错误与边界

至少列出输入错配、参数误读及一次安全失败示例。涉及配准、显著性或颜色编码时，给出不能由软件自动保证的条件。

## 7. 交付检查

中英文步骤/控件/参数一致；链接及文件存在；命令在干净会话运行；图文人工复核；许可证/引用正确；无私有路径；更新Changelog和文档版本。
